# Bright Bots Academy — лендинг детской школы робототехники

## Название

**Bright Bots Academy** — одностраничный сайт детской школы робототехники и программирования в Остине, штат Техас (Austin, TX). Название, как и остальные фактические данные на странице, пока вымышлено и подлежит замене.

## Решаемая задача

Сайт помогает школе привлекать родителей и получать заявки на **бесплатное пробное занятие**. Он кратко объясняет, чему учатся дети, показывает преподавателей, тарифы и расположение, снимает главные возражения («нужен ли опыт», «дорого ли», «можно ли просто попробовать») и переводит посетителя к одному действию — написать в WhatsApp.

Вторая задача — измеримость: каждый клик по WhatsApp, телефону и маршруту отправляется в Google Analytics 4 или Google Tag Manager, поэтому владелец школы видит, откуда приходят заявки и какие кнопки работают лучше.

## Пользователь

- **Основной посетитель** — родитель ребёнка 6–10 лет в Остине, который ищет развивающий STEM-кружок и хочет сначала прийти на пробное занятие без оплаты и обязательств.
- **Второй пользователь** — владелец/администратор школы: он меняет реальные имена, цены, адрес и телефон, смотрит аналитику и обновляет контент без помощи разработчика (все такие места помечены `data-placeholder`).

> ⚠️ Все тексты на сайте — **только на английском**. Все имена преподавателей, цены, адрес и телефон в текущей версии — плейсхолдеры.

## Что есть на странице

1. Шапка с навигацией, кнопкой звонка, WhatsApp-CTA и переключателем темы.
2. Hero с оффером «Build Robots. Learn to Code. Have Fun!» и анимированным роботом.
3. Блок цифр (количество детей, лет опыта и т.п.) с анимированными счётчиками.
4. «What kids will learn» — 4 карточки навыков.
5. «Meet our teachers» — 4 карточки преподавателей.
6. Pricing — бесплатное первое занятие и регулярное Membership.
7. Location — адрес, карта и ссылка «Get directions».
8. Contact — способы связи и главная кнопка заявки.
9. Footer и плавающая кнопка WhatsApp.

## Стек и структура

Статический сайт: **HTML + CSS + ванильный JavaScript**, без сборщика и фреймворков.

```
p01/
├── index.html               # разметка и весь контент
├── assets/css/styles.css    # токены, сетка, анимации, адаптив, тёмная тема
├── assets/js/main.js        # шапка, мобильное меню, тема, reveal, счётчики, параллакс
├── assets/js/analytics.js   # GA4/GTM, клики, глубина прокрутки
├── assets/img/              # favicon, робот и 4 аватара (SVG)
├── AGENTS.md                # правила работы над проектом
└── README.md                # эта инструкция
```

Папка `examples/` с референс-скриншотом заказчика **в репозиторий не включается** (добавлена в `.gitignore`).

Внешние запросы — только Google Fonts (Baloo 2 и Manrope) и аналитические теги (после настройки ID).

## Запуск локально

```bash
git clone https://github.com/alezarov/demo-landing-roboto.git
cd demo-landing-roboto
python3 -m http.server 4173 --bind 127.0.0.1
```

Открыть <http://127.0.0.1:4173/index.html>. Файл можно открыть и напрямую через `file://`, но сервер ведёт себя точнее (шрифты, SVG, относительные пути).

Полезные режимы:

- `index.html?dev=1` — пунктиром обводит все плейсхолдеры.
- `index.html?ga_debug=1` — пишет аналитические события в консоль.

## Замена плейсхолдеров

Все заменяемые данные помечены `data-placeholder="…"`. Проверить их помогает режим `?dev=1`.

| Ключ | Где находится | Сейчас |
| --- | --- | --- |
| `school-name` | шапка, подвал, копирайт | `Bright Bots` / `Bright Bots Academy` |
| `address-short` | строка под hero | `1234 Innovation Dr, East Austin` |
| `teacher-1..4-name` / `teacher-1..4-bio` | «Meet our teachers» | Alex Rivera, Priya Nair, Jordan Kim, Sam Ortiz + биографии |
| `price-trial` | Pricing | `$0` |
| `price-monthly` | Pricing | `$190` |
| `price-format` | Pricing | `monthly membership` |
| `full-address` | Location и подвал | `1234 Innovation Drive, Suite 210, Austin, TX 78701` |
| `whatsapp-number` / `phone-number` | Contact и подвал | `+1 (512) 555-0147` |

Что ещё нужно поправить вручную:

1. **Номер телефона** — цифры `15125550147` зашиты во всех ссылках `wa.me` и `tel:`. Заменить везде.
2. **Карта и маршрут** — обновить `src` у `<iframe>` и параметр `destination=` в ссылке Google Maps.
3. **Фото преподавателей** —svg-аватары заменить реальными фото, сохранив осмысленные `alt`.
4. **Hero** — при желании заменить иллюстрацию на фото с `alt="Kids building Arduino robots"`.
5. **SEO и соцсети** — обновить `<title>`, `meta description`, `og:*` и блок JSON-LD в `<head>`; для `og:image` лучше растровое изображение 1200×630.

## Заявки и аналитика

Отдельной HTML-формы нет: заявка отправляется через ссылку WhatsApp с готовым текстом:

```
Hi! I'd like to book a FREE trial robotics class for my child (age ___). What times are available?
```

Одна и та же кнопка «Book a FREE Trial Class» стоит в hero, Pricing и Contact, плюс в шапке, мобильном меню, подвале и плавающей кнопке. Каждая ссылка несёт `data-wa="<location>"`, поэтому аналитика знает, откуда был клик.

Настройка: в начале `assets/js/analytics.js` задать `ga4MeasurementId` (например, `G-ABC123XYZ`) и/или `gtmContainerId` (например, `GTM-XXXXXXX`). Пока ID содержат `XXXX`, теги не загружаются, но события всё равно попадают в `window.dataLayer`.

| Событие | Когда срабатывает | Ключевые параметры |
| --- | --- | --- |
| `whatsapp_click` | клик по любой кнопке WhatsApp | `link_location`, `link_text`, `link_url` |
| `phone_click` | клик по `tel:` | `link_location`, `link_url` |
| `directions_click` | клик «Get directions» | `link_location`, `link_url` |
| `scroll_depth` | прокрутка 25 / 50 / 75 / 100 % | `percent_scrolled` |

`whatsapp_click` — основное событие-конверсия. Повторные клики по одной кнопке в течение 600 мс не учитываются.

## Светлая и тёмная тема

Переключатель есть в шапке (иконка луна/солнце) и в мобильном меню (с подписью). При первом визите тема берётся из системной настройки `prefers-color-scheme`; после клика выбор сохраняется в `localStorage` (ключ `theme`). Тема применяется до первой отрисовки, без мигания. Тексты, структура и анимации при переключении не меняются — только палитра.

## Проверки и доступность

- Lighthouse (desktop, локальный сервер): Accessibility **1.0**, Best Practices **1.0**, SEO **1.0** — в обеих темах.
- Нет горизонтального скролла на ширинах 320–1440 px.
- Соблюдается `prefers-reduced-motion`; при выключенном JavaScript контент всё равно виден.
- У декоративных SVG `aria-hidden`, есть skip-link и видимые состояния фокуса.
- Поддерживаются современные Chrome, Edge, Firefox и Safari.
